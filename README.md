# Shatter

Shatter is a browser-native gravity-well rock shooter. Fly on momentum, curve
shots around the star, break armored rocks into fragments, and use the Warhead
torpedo when its ten-second recharge gives you the edge.

## Install and run

```sh
npm ci
npm run dev
```

Open the local Vite URL. To create the static production site, run `npm run
build`. The finished site is in `dist/` and can be served by any static file
server.

## Controls

- Arrow keys or WASD: rotate and thrust
- Space: fire the gun
- F: launch the guided torpedo
- P or Escape: pause/resume; Escape backs out of menus
- M: mute audio
